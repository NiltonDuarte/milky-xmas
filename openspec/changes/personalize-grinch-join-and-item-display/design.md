# Design

## Decisions

- Keep fight controls on the shared message and put Join on an ephemeral message. The private button carries the original encounter message ID, so the shared application service continues to validate and record the normal Join action.
- Check membership before opening the panel and replace the player's previous panel when they reopen registration. After enrollment, update the private message in place to clear its components.
- Add the Bad deeds increase inside the existing atomic Yellow Snowball transfer. Share the compact inventory and item formatting between adapters.
