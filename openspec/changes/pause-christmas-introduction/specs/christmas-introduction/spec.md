## ADDED Requirements

### Requirement: Introduction turned off

While the Christmas introduction is turned off, enabling a channel for the boss SHALL save the choice without posting the introduction. This replaces the announcement described by `discord-channel-setup`.

#### Scenario: Configure a boss channel

- **GIVEN** the introduction is turned off
- **WHEN** a moderator enables the boss in a channel for the first time
- **THEN** the choice is saved and nothing is posted in the channel
