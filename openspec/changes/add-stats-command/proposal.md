## Why

Players and moderators want to see what happened in the event: server totals and leaderboards.

## What Changes

- `/stats` opens a private panel with a drop-down for server stats or leaderboards, a second one below it, and the server stats until something is picked.
- The second drop-down holds Server stats and the leaderboards: Bad eggs, Good eggs, Throwers, Gifters, and Plant moms and dads.

## Capabilities

### New Capabilities

- `event-stats`: the server totals and leaderboards.

### Modified Capabilities

None.

## Impact

A new command in both adapters and reads of the kept history. Grinch fight leaderboards are not included; how to show them is still to be decided.
