## Decisions

- Add up the players' current aura: positive values are good deeds and negative values bad deeds. Past actions that cancelled out are not counted twice, and no history is needed.
- The command does not check the event end date; the moderator chooses when to use it, which also allows testing.
- Defer privately and post the result to the channel, so refusals and failures stay private.
- One picture is used for every verdict until a picture for bad deeds exists.

## Risks

- Test data counts until it is cleared before the event.
- The picture supplied is a watermarked Vecteezy preview. It needs the licensed download or a replacement before the event.
