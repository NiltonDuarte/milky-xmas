# Proposal

## Why

Each Discord server needs to choose where Milky Xmas commands and Grinch encounters can run.

## What Changes

- Invite moderators to configure the bot when it joins a Discord server.
- Let moderators manage separate command and boss channel permissions.
- Publish the Christmas introduction in each newly configured boss channel.

## Capabilities

### New Capabilities

- `discord-channel-setup` covers onboarding, channel permissions, and the Christmas introduction.

### Modified Capabilities

## Impact

Discord startup, interaction routing, and Grinch scheduling use persisted server settings. The local chat continues to use its fixtures.
