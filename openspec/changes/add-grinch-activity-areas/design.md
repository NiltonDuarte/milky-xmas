## Decisions

- **Events, not text, in the state.** The fight stores up to five recent events per side: attacks for the players, and phase changes, snowball hits, gifts, and Snowballs for the Grinch. The text comes later, from the event and its roll. The state stays small and the wording can change without touching stored fights.
- **Randomness from the shell.** `GrinchEncounter.Play` draws one number per move and the core copies it into the events it creates. The adapter picks a line as `pool[roll % len(pool)]`, so the same fight shows the same lines on replay and the core stays deterministic. When the countdown ends by itself there is no move, so the start line is chosen from the deadline time.
- **One text package for both interfaces.** `grinchtext` writes the lines for Discord and the local chat. Discord mentions players, and the local chat prints the user ID.
- **What counts as a player attack.** A snowball hit, a safe defense, an attack, or a final hit. A miss is the Grinch's doing and a gift or Snowball taken back is the player's gain, so both belong to the Grinch's area.
- **Fixed height.** Each area always has the same number of lines: the Grinch's takes six (three events of two lines) and the players' takes five. Missing lines are filled with an invisible character, because Discord drops plain spaces and blank lines. Every line the Grinch or a player says is written to fit one line, so a long line does not make the message taller.
- **A box of its own.** Discord gives a container only an accent bar colour and no background colour, and a container cannot hold another. The areas are a second top-level container in the darkest accent, so they stand apart from the panel above. A code block would give a darker background, but it does not render player mentions.
- **Buttons in the box.** The buttons of the phase are the last components of the activity box. The registration keeps its Start button in the panel, because it has no activity box.
- **Cards in the box.** The player cards are the last items of the activity box, below the buttons, and no longer boxes of their own. A container cannot hold another, so a card is a text, and a coloured square in front of the name stands for the HP the box can no longer colour: 🟩 above 50%, 🟨 to 50%, 🟧 to 25%, and ⬛ at zero.
- **Component budget.** The panel and the activity box, with its separators, two texts, buttons, eight cards, and a summary, take about 30 components in the largest board, under Discord's 40.
