## Decisions

- **Same path as yellow.** Both types go through the shared inventory transfer, so the move is atomic: both inventories change together or neither does, and an invalid recipient is refused first.
- **No aura change for normal.** Yellow's Bad deeds cost stays; a plain snowball has none.
- **Suggestions follow ownership.** With no snowball of either kind, the type list is empty. Discord shows its usual "no options" state, and a typed value is refused with the existing messages.
- **Local chat** keeps defaulting to the normal type when none is given.
